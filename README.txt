AGGIORNAMENTO COLLAPSE TICKETS

1. In Supabase apri SQL Editor.
2. Incolla ed esegui il contenuto di supabase-delete-ticket.sql.
3. Su GitHub: Add file -> Upload files.
4. Carica e sostituisci:
   - index.html
   - app.js
   - styles.css
   - ticket-template.jpg
5. Commit changes.
6. Aspetta il redeploy automatico di Vercel e ricarica con Cmd+Shift+R.

NUOVE FUNZIONI
- Scarica il ticket completo dalla scheda Aggiungi.
- Scarica di nuovo il ticket da ogni riga della lista Invitati.
- Elimina invitato con conferma.
